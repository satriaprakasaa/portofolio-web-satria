04. Featured Projects

Real-Time IoT Environmental Monitoring System

Proyek ini mengimplementasikan sistem pemantauan suhu dan kelembapan lingkungan secara real-time berbasis Internet of Things (IoT). Simulasi mikrokontroler ESP32 membaca data telemetri dari sensor DHT22, mengirimkan payload berformat JSON ke broker MQTT publik HiveMQ, dan menampilkan visualisasi data pada Dashboard Node-RED berdesain Dark Theme / Modern UI.

Real-Time River Water Level IoT Monitoring System

Merancang sistem pemantauan air berbasis IoT Edge (ESP32 & sensor ultrasonik HC-SR04). Mentransmisikan telemetri JSON via protokol MQTT ke Node-RED Dashboard.

SDN vs. Conventional Network Eval

Evaluasi performa latency dan throughput jaringan konvensional vs SDN (Ryu Controller & Mininet). Menganalisis initial packet delay akibat reactive flow entry OpenFlow v1.3. Jurnal ELKOMIKA (Sinta 3).

Enterprise Network Architecture & High Availability Simulation

Merancang topologi jaringan SME dengan Inter-VLAN Routing, DHCP, dan Standard ACL. Implementasi Hot Standby Router Protocol (HSRP) untuk failover redundancy <2 detik.

Campus Network Security Risk Assessment

Memvalidasi silang keamanan 3 domain (SSH, OpenPGP, TLS) via OpenSSL & Kali Linux. Menyusun matriks Risk Register serta remedi penutupan celah root login SSH dan MitM.
